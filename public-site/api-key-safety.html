Use a key made for Tracal.

Create a dedicated key

Do not reuse a key from another app or project. Apply the provider’s lowest practical permissions, spending limit, and usage alerts.

Stored on this iPhone

Tracal stores keys with WhenUnlockedThisDeviceOnly Keychain protection. Keys are excluded from SwiftData, local backups, UserDefaults, diagnostics, and the app bundle.

Sent only to the provider

The selected key is attached only to requests sent over HTTPS to that provider’s hardcoded official API origin. Tracal has no routing intermediary or backend.

Rotate when needed

Delete a key in Tracal Settings and revoke it in the provider console if the phone, key, or provider account may be compromised. A jailbroken or otherwise compromised device can weaken platform protection.

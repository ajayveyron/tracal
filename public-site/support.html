Tracal support.

Connect a provider

Open Settings, choose OpenAI, Anthropic, or Gemini, create a dedicated API key, enable the consent control, then save and test. A small test request may incur a provider charge.

Analysis fails

Confirm the selected provider key is active, the provider account has quota or balance, and the chosen model is available. Inputs remain in the composer after a failed request.

Costs differ

Tracal estimates cost from provider-reported tokens and the bundled public price catalog. Free tiers, discounts, taxes, and price changes are reflected only in the provider’s billing dashboard.

Backup

Use Export backup in Settings before deleting Tracal or moving phones. Backups contain local meals, goals, protected photos, and usage history. They never contain provider API keys.

Refunds and contact

Use Apple for purchases and refunds. For product support, contact Ajay Pawriya.

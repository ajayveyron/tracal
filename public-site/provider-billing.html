The app and AI are billed separately.

Tracal purchase

Apple charges once for the paid app. That purchase does not include OpenAI, Anthropic, or Gemini API usage.

Provider account

Cloud analysis uses the API key and billing account you connect. Consumer ChatGPT, Claude, and Gemini subscriptions do not necessarily include API credits.

Estimated API cost

Tracal combines provider-reported usage with a dated public price catalog. Retries and invalid results may still be billable. Unknown usage or pricing is shown as unknown, never zero.

Source of truth

Free tiers, discounts, taxes, cached-token rules, and price changes can differ. The provider dashboard and invoice are the billing source of truth.

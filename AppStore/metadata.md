## Description

Tracal is a private calorie tracker that keeps meals, goals, photos, and AI usage history on your iPhone.

Log with text or a photo. Use Apple Intelligence for supported offline text analysis, or connect your own OpenAI, Anthropic, or Gemini API key for cloud estimates. Requests go directly to the provider you select.

Cloud AI requires a separately billed provider API account. ChatGPT, Claude, and Gemini consumer subscriptions do not automatically include API access. Tracal shows provider-reported tokens and estimated API cost; your provider dashboard is the billing source of truth.

Nutrition values are estimates, not medical advice. Review and correct entries before relying on them.
